# تطبيق الأندرويد - نظام التسعير الشامل للورش

تم تجهيز مشروع الأندرويد بالكامل وبداخله ملف النظام الخاص بك (`app/src/main/assets/index.html`) ليعمل **بدون إنترنت (Offline)** مع دعم كامل لـ:
- حفظ البيانات والمشاريع محلياً (`localStorage`).
- الطباعة وحفظ عروض الأسعار بصيغة **PDF** مباشرة من الهاتف (`window.print()`).
- تصدير واستيراد النسخ الاحتياطية (`.json`) واختيار الصور للشعار والخامات.

## طريقتان لاستخراج ملف التثبيت (APK):

### الطريقة الأولى: عبر Android Studio (على الكمبيوتر)
1. فك الضغط عن هذا المجلد.
2. افتح برنامج **Android Studio** واختر **Open** ثم حدد المجلد.
3. انتظر حتى ينتهي من تحميل الإعدادات (Gradle Sync).
4. من القائمة العلوية اختر: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. ستجد ملف `app-debug.apk` جاهزاً للنقل والتثبيت على أي هاتف أندرويد.

### الطريقة الثانية: عبر GitHub (بدون تثبيت Android Studio)
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub وارفع إليه هذه الملفات.
2. اذهب إلى تبويب **Actions** في المستودع.
3. سيبدأ بناء ملف الـ APK تلقائياً، وبعد دقيقتين ستجد ملف **WorkshopPricing-APK** جاهزاً للتحميل.
